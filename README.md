# Mueblería Medellín

Sitio web responsive para Mueblería Medellín, diseñado con una identidad visual en negro, marfil y dorado inspirada en el monograma de la marca.

## Vista local

```bash
python3 -m http.server 4173
```

Después abre `http://localhost:4173`.

## Configuración

Actualiza `config.js` con los datos reales del negocio:

- Usuario de Instagram
- Número de WhatsApp con código de país
- Número formateado para mostrar
- Dirección

## Estructura

- `index.html`: contenido y estructura del sitio
- `styles.css`: identidad visual y diseño responsive
- `script.js`: navegación, animaciones y formulario de WhatsApp
- `config.js`: datos editables del negocio
- `assets/`: logo y recursos preparados para la web
